# Brassen Tower

[**게임 바로 플레이**](https://beomjun1101.github.io/brassen-tower/)

황동 첨탑을 오르는 2.5D 액션 로그라이크입니다. 전투를 마치면 보상 하나를 받습니다. 갈림길에서 다음 전투에 적용할 효과를 고른 뒤 열린 출구에 닿으면 위층으로 올라갑니다. 5층마다 들르는 쉼터에서 의뢰 게시판과 상점, 정비 시설을 이용할 수 있습니다.

일반 플레이는 1층부터 20층까지입니다. 9층과 19층에는 보스전이 있습니다. 시작 화면 오른쪽 아래에서 게임 관리자 모드를 연 뒤 `/`로 후반 층을 테스트할 수 있습니다. 관리자 이동은 일반 플레이의 저장 기록과 분리됩니다.

## 실행과 조작

이 폴더의 `index.html`을 브라우저에서 열 수 있습니다. 로컬 서버로 실행하려면 이 폴더에서 `python3 -m http.server 8000`을 실행하고 [localhost:8000](http://localhost:8000/)을 여세요.

| 동작 | 조작 |
| --- | --- |
| 이동 | WASD 또는 방향키 |
| 공격 | 스페이스바를 한 번씩 누르거나 마우스 왼쪽 클릭 |
| 대쉬 | Shift |
| 패링 | F |
| 시설 상호작용 | 가까이에서 E 또는 시설 클릭 |
| 가방 | 아이템 클릭으로 즉시 사용 또는 장착 |
| 상태창 | Q 또는 화면 상단의 상태창 버튼 |
| 일시정지 | Esc 또는 화면 상단의 일시정지 버튼 |
| 메뉴·보상 선택 | Tab으로 항목 이동, 스페이스로 선택 |

터치 화면에서는 게임 아래의 조작 버튼을 사용하세요. 진행 기록과 음악 설정은 사용 중인 브라우저의 사이트 저장소에 보관합니다.

상태창에서는 착용 중인 장비와 착용 가능한 장비, 능력치, 의뢰를 확인합니다. 부위별로 장비를 두 개까지 착용할 수 있으며, 두 자리가 차면 새 장비가 가장 먼저 착용한 장비를 교체합니다. 착용 중인 장비는 가방 목록에서 빠집니다. 상태창이나 일시정지 메뉴가 열려 있는 동안 게임은 멈춥니다. 일시정지 메뉴에서 **저장하고 나가기**를 선택한 뒤 이어하면 저장한 위치와 전투 상태에서 계속할 수 있습니다. 층 입장용 자동 저장으로 이어하면 저장된 층의 입장부터 시작합니다.

처음 1층부터 2층 초입까지 조작, 보상, 상태창, 가방을 사용할 때 해당 버튼과 패널 옆에 짧은 안내가 표시됩니다. 5층에서는 쉼터 시설을 안내합니다. 확인한 안내는 같은 브라우저에서 다시 표시되지 않습니다.

적의 공격에 맞기 0.125초 전부터 맞은 뒤 0.125초 사이에 패링하면 그 타격 한 번을 막습니다. 패링에 실패하면 5초간 다시 쓸 수 없습니다.

전투가 시작되면 플레이어는 0.5초 뒤, 적은 1초 뒤부터 움직입니다. 레벨이 오를 때마다 새 최대 체력의 5%를 회복합니다.

기본 공격 간격은 0.1초입니다. 장비, 갈림길, 무기에 따라 공격 간격이 달라집니다. 유격병은 측면을 노리고, 파쇄병은 강한 근접 공격을 씁니다. 저격병은 멀리서 조준하고, 공작병은 폭발 위험 구역을 만듭니다.

처치 시 회복은 드물게 나오는 등반 스탯입니다. 최대 10까지 오르며, 사망하면 모두 잃습니다. 이미 10이면 복합 보상에는 나머지 효과만 표시됩니다.

층 보상 세 가지에는 효과가 약한 공급품이나 능력치를 깎는 장비가 섞일 수 있습니다. 불이익은 선택 전에 표시되며, 일반 보상이 항상 한 가지 이상 나옵니다.

## 난이도

새 등반을 시작할 때 능력치와 함께 난이도를 고릅니다. 난이도 항목에 키보드 초점이 있으면 좌우 방향키로 선택을 바꿀 수 있습니다. 기본값은 쉬움이며, 선택한 난이도는 이어하기와 사망 후 재등반에도 유지됩니다.

| 난이도 | 적 체력 | 적 공격 피해 | 모닥불 회복량 |
| --- | --- | --- | --- |
| 쉬움 | 기본 | 기본 | 완전 회복 |
| 보통 | +20% | +12% | 최대 체력의 2/3 |
| 어려움 | +45% | +28% | 최대 체력의 1/3 |

모닥불은 10층마다 나옵니다. 회복량은 정수로 반올림하고, 체력은 최대치를 넘지 않습니다.

난이도가 높을수록 적이 더 빠르게 움직이고 공격하며, 공작병의 기뢰와 보스의 연속 공격이 늘어납니다. 어려움에서는 저격병의 연속 사격이 한 발 늘어납니다.

## 직업과 무기

등반가는 장검으로 시작합니다. 10층 성당에서 직업을 선택하고 20층 신전에서 상위 직업으로 전직할 수 있습니다. 마법사와 궁수는 장거리, 결투가는 중거리, 격투가는 근거리에서 싸웁니다.

| 직업 | 무기와 공격 방식 |
| --- | --- |
| 수호병 · 철벽 수호병 | 전투 망치로 적을 비틀거리게 합니다. 대형 전투 망치는 그 시간을 늘립니다. |
| 전열 집행관 | 장대 도끼로 먼 거리에서 적을 찍습니다. |
| 결투가 · 속검 결투가 | 레이피어로 좁은 각도의 먼 적을 찌릅니다. 기병도는 넓게 휘둘러 적 하나를 벱니다. |
| 갑주 파쇄인 | 대검으로 적의 방어를 뚫습니다. |
| 척후병 · 틈새 길잡이 | 쌍단검으로 가까운 적을 빠르게 벱니다. 쌍검은 짧게 전진한 뒤 벱니다. |
| 반격 척후병 | 갈고리 검으로 패링 직후 강한 반격을 합니다. |
| 마법사 · 비전술사 | 지팡이로 마력탄을 쏘고, 전직 후에는 마력구를 날립니다. |
| 궁수 · 명사수 | 활로 먼 적을 사격하고, 전직 후에는 쇠뇌를 씁니다. |
| 격투가 · 격투 달인 | 권갑으로 가까운 적을 치고, 전직 후에는 톤파를 씁니다. |

## 지도 생성

전투 층에 입장할 때 굴리는 주사위가 전장의 지역, 환경, 배치를 정합니다. 주사위가 멈추면 스페이스바를 누르거나 게임 화면을 클릭 또는 탭해 전투에 들어갑니다. 전장에는 계단과 높낮이, 방을 잇는 통로가 있습니다.

`floor-graph.js`는 주사위와 층 시드에 따라 방을 나누고, 벽 사이에 통로를 만듭니다. `map-planner.js`의 가중치는 방 수와 분할 위치 같은 생성 조건에 반영됩니다. 5·10·15·20층 쉼터도 입장할 때 생성합니다.

생성된 지도는 실제 이동 규칙으로 검사합니다. 시작 위치에서 전투에 필요한 지점과 쉼터 시설에 닿을 수 있는지 확인합니다. 검사에 실패하면 정해진 순서로 다시 생성하고, 경로를 확보하지 못하면 안전한 배치를 사용합니다. 같은 층과 시드에서는 같은 지도가 만들어집니다.

지도 생성과 모델 실행은 브라우저에서 오프라인으로 이루어집니다. 가중치를 다시 만들려면 저장소 루트에서 `node tools/train-map-planner.mjs`를 실행하세요. 배포된 가중치를 확인하려면 `--check`를 붙이세요.

## 소스와 배포

`index.html`은 화면 구조를, `styles.css`는 인터페이스를 정의합니다. `game.js`는 게임 진행을 맡고, `render.js`와 `title.js`는 배경과 캐릭터를 Canvas에 그립니다. 나머지 스크립트는 층과 보상, 성장, 마을, 소리를 구성합니다.

HTML에서 CSS와 JavaScript를 상대 경로로 불러오는 정적 게임입니다. GitHub Pages에서 바로 배포하려면 **Settings → Pages**의 게시 원본을 **Deploy from a branch**로 두고 소스가 들어 있는 브랜치의 **/(root)**를 선택하세요. `.nojekyll`로 별도 빌드 없이 소스 파일을 게시합니다. [GitHub Pages 게시 설정](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
