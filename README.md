# Brassen Tower

[**게임 바로 플레이**](https://beomjun1101.github.io/brassen-tower/)

주사위로 변하는 시련을 돌파하며 1,332층을 오르는 2.5D 액션 로그라이크입니다. 갈림길에서 다음 층에 적용할 효과를 고르고 5층마다 쉼터를 만납니다.

현재 일반 플레이는 1층부터 20층까지입니다. 시작 화면 오른쪽 아래에서 게임 관리자 모드를 연 뒤 `/`로 후반 층을 테스트할 수 있습니다. 관리자 이동은 일반 세이브와 분리됩니다.

## 실행과 조작

이 폴더의 `index.html`을 브라우저에서 열 수 있습니다. 로컬 서버로 실행하려면 이 폴더에서 `python3 -m http.server 8000`을 실행하고 [localhost:8000](http://localhost:8000/)을 여세요.

| 동작 | 조작 |
| --- | --- |
| 이동 | WASD 또는 방향키 |
| 공격 | 스페이스 또는 마우스 왼쪽 클릭 |
| 회피 | Shift |
| 시설과 사건 장치 상호작용 | 가까이에서 E 또는 장치 클릭 |
| 메뉴·대화 선택 | Tab으로 항목 이동, 스페이스로 선택 |

터치 화면에서는 게임 아래의 조작 버튼을 사용하세요. 진행 기록과 음악 설정은 사용 중인 브라우저의 사이트 저장소에 보관합니다.

## 지도 생성

1–20층의 전장과 5·10·15·20층 쉼터를 입장할 때 생성합니다. 계단이 있는 전장과 9층·19층 보스전도 포함합니다. 첫 전투 전에 들르는 진료소는 별도로 구성했습니다.

`floor-graph.js`는 이야기 선택, 주사위, 층 시드에 따라 방을 나누고, 벽을 세워 방 사이에 지나다닐 통로를 만듭니다. 구조와 호송에서는 탈출 동선을 잇고, 수색에서는 여러 방으로 갈라지는 길과 우회로를 만듭니다. 이야기와 주사위 사례로 학습한 `map-planner.js`의 가중치는 방 수와 분할 위치 같은 생성 조건에 반영됩니다.

생성된 지도는 실제 이동 규칙으로 검사합니다. 출발 지점에서 목표물, 사건 장치, 쉼터 시설, 출구에 도달할 수 있는지 확인합니다. 검사에 실패하면 정해진 순서로 다시 생성하고, 재시도 후에도 경로를 확보하지 못하면 안전한 배치를 사용합니다. 같은 층에서 선택과 시드가 같으면 같은 지도가 만들어집니다.

지도 생성과 모델 실행은 브라우저에서 오프라인으로 이루어집니다. 가중치를 다시 만들려면 저장소 루트에서 `node tools/train-map-planner.mjs`를 실행하세요. 배포된 가중치를 확인하려면 `--check`를 붙이세요.

## 소스와 배포

`index.html`은 화면 구조를, `styles.css`는 인터페이스를 정의합니다. `game.js`는 게임 진행을 맡고, `render.js`와 `title.js`는 배경과 캐릭터를 Canvas에 그립니다. 나머지 스크립트는 층과 보상, 성장, 이야기, 마을, 소리를 구성합니다.

HTML에서 CSS와 JavaScript를 상대 경로로 불러오는 정적 게임입니다. GitHub Pages에서 바로 배포하려면 **Settings → Pages**의 게시 원본을 **Deploy from a branch**로 두고 소스가 들어 있는 브랜치의 **/(root)**를 선택하세요. `.nojekyll`로 별도 빌드 없이 소스 파일을 게시합니다. [GitHub Pages 게시 설정](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
